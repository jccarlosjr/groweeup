# Growee Up — Website Institucional

Site institucional da Growee Up (agência de growth / marketing digital), construído com React + Vite, Tailwind CSS, Framer Motion e GSAP.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion (entrada, micro-interações, page transitions)
- GSAP ScrollTrigger (linha do processo)
- React Router DOM
- Lucide React

## Scripts

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

## Páginas

- `/` — Home (hero, métricas, produtos, processo, contato)
- `/sobre` — Sobre a empresa
- `/termos` — Termos de Serviço
- `/privacidade` — Política de Privacidade (LGPD)

## Branding

Logos em `src/assets/` e `public/` (`logo-dark`, `logo-light`, `name`, `name-2`). Paleta e motion definidos em `src/styles/tokens.css` e no `plano.md`.
